# Specs

Source-of-truth specs live here as `{domain}/spec.md`, one directory per
domain. See `../config.yaml` and
`~/.claude/skills/_shared/openspec-convention.md` for the file convention.

Los cuatro dominios actuales (`resumen-sesion`, `cierre-sesion`,
`gestion-cajeros`, `reconciliacion-lineas`) provienen del cambio
`complete-cloud-functions`, archivado en
`../changes/archive/2026-08-06-complete-cloud-functions/`. Este directorio
estaba vacío antes de él, así que sus specs delta se publicaron íntegras, sin
fusión sobre un spec previo.
